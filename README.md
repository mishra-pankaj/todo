📝 Simple To-Do List App
A lightweight and minimal to-do list web app built with vanilla JavaScript. 
It allows users to add and delete tasks, with persistent storage using the browser's localStorage.

🔧 Features
✅ Add new tasks
🗑️ Delete existing tasks
💾 Persistent data using localStorage
📱 Clean and responsive UI (customizable)

🚀 Technologies Used
HTML – For structure
CSS – For styling
JavaScript (Vanilla) – For app logic
LocalStorage – For data persistence

💡 Future Improvements
 Mark tasks as completed
 Edit task text
 Add filters (All / Completed / Active)
 Add due dates or priorities
